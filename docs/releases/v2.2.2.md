StockViewer v2.2.2 — 검색창을 숨길 때 작업표시줄 앱 표시가 잠깐 사라지는 현상을 수정했습니다.

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임이 포함되어 있습니다.

변경 내용:

- 검색창을 X로 숨기기 전에 가격창의 작업표시줄 항목을 먼저 등록합니다. 가격창이 남아 있는 동안 앱 표시가 사라졌다 다시 나타나는 틈을 없앴습니다.
- 검색창 복원 시에도 검색창을 먼저 표시한 뒤 가격창의 대표 표시를 해제합니다.
- 대표 가격창을 닫을 때 창이 실제로 사라지기 전에 다른 가격창이 작업표시줄 표시를 이어받습니다.
- v2.2.1의 저장·불러오기 3초 빨간 버튼 표시, 선택 그룹 더블 우클릭 닫기, 작업표시줄 종료 시 전체 창 종료를 포함합니다.

기존 다중 선택·그룹 이동·바탕화면 드래그 선택·배치 저장·불러오기·다크모드·국내와 미국 시간외 시세 갱신을 유지합니다.

Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. `SHA256SUMS.txt`로 다운로드 파일을 확인할 수 있습니다.
