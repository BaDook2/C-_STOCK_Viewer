StockViewer v2.1.1 — 첫 가격 표시와 종료 동작을 개선했습니다.

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임을 포함하며 인터넷 연결이 필요합니다. 계좌 로그인이나 증권사 API 키는 필요하지 않습니다.

수정 내용:

- 마우스를 올려도 글자색·글자 배경·불투명도를 바꾸지 않고 컨트롤의 바깥 배경·테두리만 변경합니다. 검색 글자에 회색 강조가 생기던 효과를 제거했습니다.
- 첫 유효 가격을 받은 뒤 가격·등락률을 채워 팝업을 표시합니다. 처음에 `—`가 잠시 보이지 않습니다.
- 3초 이상 데이터가 도착하지 않으면 종목명이 포함된 안내 팝업을 띄웁니다. 대기 중에도 다른 종목을 검색할 수 있으며, 늦게 도착한 응답이 창을 갑자기 만들지 않습니다. 다시 검색하면 재시도합니다.
- 같은 종목을 다시 열 때 새 데이터가 도착하기 전까지 기존 가격창을 유지합니다.
- Windows 작업표시줄의 창 닫기·Alt+F4와 Mac Dock 종료 시 모든 가격창과 진행 중인 시세 요청까지 종료합니다. 앱 안의 X는 기존처럼 가격창이 있을 때 검색창만 숨깁니다.

v2.1.0의 다크모드, 국내 KRX/NXT 및 미국 데이마켓·시간외 갱신, 마감 회색 표시, 가격창 겹침 방지 기능을 유지합니다.

Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. 최초 실행 시 macOS 보안 확인이 표시될 수 있습니다. `SHA256SUMS.txt`로 파일 체크섬을 확인할 수 있습니다.
