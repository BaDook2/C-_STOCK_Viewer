StockViewer v2.2.4 — 국내 주식·ETF 가격을 토스증권 비로그인 통합 시세로 전환했습니다.

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임이 포함되어 있으며 증권사 로그인·API 키 입력은 필요하지 않습니다.

변경 내용:

- 국내 주식은 토스가 제공하는 KRX+NXT 통합 현재가를 표시합니다. NXT 미지원 ETF 등은 토스 KRX 시세를 표시합니다. 툴팁에 제공처·거래소 기준·기준시각·수신시각을 표시합니다.
- 토스의 실제 거래일별 KRX·NXT 달력과 종목별 시간외 지원 정보로 정규장·프리·애프터마켓 및 장 마감 상태를 판단합니다. 거래시간을 확인할 수 없는 경우 마감으로 단정하지 않습니다.
- 국내 시세 오류나 종목 누락 시 다른 제공처로 자동 전환하지 않고 마지막 유효 가격과 불투명 배경을 유지하며 재시도합니다. HTTP Retry-After를 준수합니다.
- 종목 검색은 기존 네이버 자동완성을 유지합니다. 미국 프리·정규·애프터마켓의 네이버 시세와 토스 미국 데이마켓도 유지합니다. 국내·미국 조회와 오류 처리는 독립적으로 동작합니다.

기존 저장·불러오기 1초 빨간 표시, 가격창 간격 없는 배치, 다중 선택·그룹 이동·더블 우클릭 닫기·맨 위 고정·다크모드·작업표시줄 표시 유지를 포함합니다.

공개 웹 조회 경로를 사용하므로 제공처 변경이나 제한의 영향을 받을 수 있습니다. Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. `SHA256SUMS.txt`로 다운로드 파일을 확인할 수 있습니다.
