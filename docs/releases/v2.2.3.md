StockViewer v2.2.3 — 저장·불러오기 버튼 표시를 1초로 줄이고 가격창을 간격 없이 배치합니다.

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임이 포함되어 있습니다.

변경 내용:

- 저장·불러오기 아이콘을 클릭하면 해당 버튼만 1초간 빨간색으로 표시하고 원래 색으로 돌아옵니다. 같은 버튼을 다시 클릭하면 마지막 클릭부터 1초를 다시 셉니다.
- 여러 종목을 검색하면 새 가격창을 기존 가격창의 아래·위 또는 옆 열에 간격 없이 붙입니다. 가격창 바깥의 투명 여백도 제거했습니다. 검색창과는 4 DIP 간격을 유지합니다.

기존 배치 저장·복원·다중 선택·그룹 이동·더블 우클릭 닫기·맨 위 고정·다크모드·작업표시줄 표시 유지·국내와 미국 시간외 시세 갱신을 포함합니다.

Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. `SHA256SUMS.txt`로 다운로드 파일을 확인할 수 있습니다.
