StockViewer v2.2.1 — 배치 버튼 표시와 선택 창 닫기·작업표시줄 동작을 개선했습니다.

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임이 포함되어 있습니다.

변경 내용:

- 저장·불러오기 버튼을 클릭하면 안내 팝업 대신 해당 버튼의 아이콘·테두리·배경을 3초간 빨간색으로 강조합니다. 같은 버튼을 다시 누르면 마지막 클릭 기준으로 3초를 다시 셉니다. 라이트·다크 모드 모두 지원하며 다른 컨트롤의 글자는 바꾸지 않습니다.
- 배치 불러오기에서 일부 시세를 받지 못한 경우에도 알림 팝업을 띄우지 않고 기존 창과 저장 파일을 보존합니다. 일반 종목 검색의 3초 미수신 안내는 유지합니다.
- Ctrl+클릭 또는 바탕화면 드래그로 선택한 가격창을 우클릭 두 번 하면 선택 창 전체를 닫습니다. 첫 우클릭은 기존처럼 선택 그룹의 고정 상태를 전환하며, 두 번째 우클릭은 버튼을 뗀 뒤 창들을 닫습니다. 선택하지 않은 창은 유지합니다.
- 검색창을 X로 숨겨도 가격창이 남아 있으면 Windows 작업표시줄에 앱을 계속 표시합니다. 가격창 하나가 대표 역할을 맡고, 그 창이 닫히면 다른 가격창이 이어받습니다. 검색창을 복원하면 검색창이 다시 대표가 됩니다.
- 작업표시줄의 종료 명령은 검색창과 모든 가격창을 함께 종료합니다. 가격창의 일반 닫기·선택 그룹 닫기는 다른 가격창을 유지합니다.

기존 다중 선택·그룹 이동·바탕화면 드래그 선택·두꺼운 선택 테두리·배치 저장·다크모드·국내와 미국 시간외 시세 갱신을 유지합니다.

Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. `SHA256SUMS.txt`로 다운로드 파일을 확인할 수 있습니다.
