StockViewer v2.2.5 — 시세 수신 진단 로그와 가격창 맨 위 고정 보완

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임이 포함되어 있으며 증권사 로그인·API 키 입력은 필요하지 않습니다.

변경 내용:

- 앱 시작·종료, 시세 HTTP 응답 코드·소요 시간·타임아웃·재시도 제한, 종목별 시세 누락·오류·복구 및 오류 지속 시간을 로컬 JSONL 파일에 자동 기록합니다. 시세 제공처·기준 시각·수신 시각, 가격창 생성·종료·교체·고정 전환·실제 OS topmost 보정도 같은 실행 세션으로 추적할 수 있습니다.
- 정상 통신·시세는 최초 및 약 1분 간격으로 요약하고 오류와 복구는 매번 기록합니다. 파일은 날짜 변경 또는 5MB마다 분할하며 오래된 로그를 7일 또는 총 10개(약 50MB) 제한에 따라 정리합니다. 다른 앱 인스턴스가 기록 중인 파일은 보존합니다.
- 로그 저장을 별도 작업으로 처리하며 저장 실패 시에도 시세 수신과 화면 조작을 계속합니다. 쿠키·인증값·URL 쿼리·요청/응답 본문·검색어·예외 원문은 저장하지 않으며 외부로 자동 전송하지 않습니다.
- Windows에서 사용자가 고정을 해제한 가격창이 실제 OS에서는 다시 맨 위로 올라오는 불일치를 보완했습니다. 열린 모든 가격창의 고정·해제 상태를 OS 상태와 맞추며 정상 창을 반복 활성화하거나 재정렬하지 않습니다.

로그 위치:

- Windows: `%LOCALAPPDATA%\StockViewer\logs`
- Mac: `~/Library/Application Support/StockViewer/logs`

장애가 발생하면 발생 시각·종목과 위 폴더의 `stockviewer-*.jsonl` 파일을 확인해 주세요. 기존 버전에서 발생한 장애의 기록을 소급 생성하지는 않습니다. 강제 종료·전원 차단 직전의 일부 기록은 남지 않을 수 있습니다.

국내 토스 KRX+NXT 통합 시세, 미국 네이버·토스 데이마켓, 불투명 배경·마감 글자색, 저장·불러오기·선택·그룹 이동·창 배치 기능을 유지합니다. Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. `SHA256SUMS.txt`로 다운로드 파일을 확인할 수 있습니다.
