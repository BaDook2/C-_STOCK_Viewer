StockViewer — 국내·미국 주식과 ETF 가격을 작은 팝업으로 확인하는 데스크톱 앱입니다.

다운로드할 파일:

- **Windows x64**: `StockViewer.exe` 하나를 실행합니다.
- **Mac Apple Silicon (M 시리즈)**: `StockViewer-macOS-arm64.zip`을 풀고 `StockViewer-macOS.app`을 실행합니다.
- **Mac Intel**: `StockViewer-macOS-x64.zip`을 풀고 `StockViewer-macOS.app`을 실행합니다.

.NET 런타임이 포함되어 있어 별도 .NET 설치가 필요 없습니다. 시세 조회에는 인터넷 연결이 필요하며 증권사 계좌 로그인이나 API 키는 필요하지 않습니다.

변경 내용:

- macOS에서 가격창이 0×0 크기로 생성되어 보이지 않던 문제를 수정했습니다.
- 최소화·닫기를 벡터 아이콘으로 교체했습니다.
- 해·달 버튼으로 라이트/다크 모드를 전환합니다. 이미 열린 가격창에도 즉시 적용되며 설정을 저장합니다.
- 국내 KRX/NXT 및 미국 프리·정규·애프터마켓과 데이마켓 시세를 갱신합니다. 미국 데이마켓은 토스증권 비로그인 공개 시세로 보완합니다.
- 거래가 완전히 마감되면 글자를 회색으로 표시하고 재개되면 등락 색상으로 돌아옵니다. 시세 확인 실패는 마감과 구분합니다.
- 새 가격창이 다른 가격창과 겹치면 아래 또는 위의 빈자리에 자동 배치합니다. 기존 창의 위치와 고정 상태는 유지합니다.

조회 목표는 1초이며 실제 갱신 속도와 지원 종목은 제공처·거래 세션·통신 상태에 따라 달라집니다. 제공처가 지원하지 않는 시세를 만들어 표시하지 않습니다.

macOS 앱은 로컬 실행용 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. 다운로드한 앱을 처음 열 때 macOS의 보안 확인이 표시될 수 있습니다.

각 운영체제의 빌드·회귀·네이티브 창 검증 및 배포 파일 시작 확인을 통과한 파일만 게시합니다. `SHA256SUMS.txt`에서 다운로드 파일의 체크섬을 확인할 수 있습니다.
