StockViewer v2.2.0 — 가격창 고정을 보강하고 배치 저장·불러오기를 추가했습니다.

다운로드:

- Windows x64: `StockViewer.exe`
- Mac Apple Silicon: `StockViewer-macOS-arm64.zip`
- Mac Intel: `StockViewer-macOS-x64.zip`

Windows는 EXE를, Mac은 ZIP을 풀고 `StockViewer-macOS.app`을 실행합니다. .NET 런타임을 포함하며 인터넷 연결이 필요합니다. 계좌 로그인이나 증권사 API 키는 필요하지 않습니다.

변경 내용:

- 여러 가격창을 우클릭으로 고정했을 때 위치만 고정되고 일부 창의 맨 위 표시가 누락되는 경우를 보완했습니다. 모든 고정 창의 실제 운영체제 속성을 개별 확인하고, 누락되면 위치나 포커스를 바꾸지 않고 다시 적용합니다. 한 창의 고정 해제가 다른 창에 영향을 주지 않습니다.
- 일시적인 시세 수신 오류가 나도 가격창의 흰색·다크 배경이 반투명하게 변하지 않습니다. 마지막 가격을 유지하고 연결 문제는 안내 문구로 표시합니다.
- 다른 창에서 이어진 우클릭 횟수로 새 창의 첫 우클릭을 더블클릭 닫기로 오인하지 않도록 했습니다.
- 테마 버튼 왼쪽에 배치 저장(디스크)·불러오기(폴더) 아이콘을 추가했습니다. 열린 가격창들의 종목·좌표·맨 위 고정 상태·종목명 표시 여부를 저장하고 앱 재실행 후에도 복원합니다.
- 불러오기는 기존 종목 창을 재사용합니다. 새 종목은 유효 시세를 받은 후 표시하고, 전체 복원에 성공하면 저장 당시 창 구성으로 맞춥니다. 일부 시세를 받지 못하면 기존 창과 저장 파일을 유지해 재시도할 수 있습니다. 모니터가 바뀌어 화면 밖에 놓인 창은 현재 화면 안으로 조정합니다. 검색 버튼이 고정 창 뒤에 가려지면 검색창을 빈자리로 옮깁니다.
- 같은 종목을 다시 검색하면 고정을 해제하고 검색창 근처의 빈 위치에 다시 배치합니다. 배치 불러오기는 저장된 고정 상태를 그대로 복원합니다.

이전 버전의 라이트·다크 모드, 국내·미국 시간외 시세 갱신, 마감 회색 표시, 첫 가격 수신 후 팝업 표시, 3초 미수신 안내와 운영체제 종료 시 전체 창 종료 동작을 유지합니다.

Mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. 최초 실행 시 macOS 보안 확인이 표시될 수 있습니다. `SHA256SUMS.txt`로 파일 체크섬을 확인할 수 있습니다.
