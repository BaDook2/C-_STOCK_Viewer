# 화면과 테마

검색 창은 286×80 DIP, 가격 팝업은 높이 32 DIP를 유지합니다. 헤더 오른쪽은 테마 토글, 최소화, 닫기 순서입니다. 버튼은 모두 벡터 선으로 그려 Windows 아이콘 글꼴이 없는 macOS/Linux에서도 같은 모양을 사용합니다.

토글은 현재 라이트 모드에서 달(다크로 전환), 다크 모드에서 해(라이트로 전환)를 표시합니다. 액션을 툴팁과 접근성 이름으로도 제공합니다. [Lucide의 선형 아이콘 설계](https://lucide.dev/contribute/icons/design-principles), [달](https://lucide.dev/icons/moon), [해](https://lucide.dev/icons/sun)를 디자인 레퍼런스로 삼았고 앱의 작은 크기에 맞춰 기본 도형으로 직접 그렸습니다. 별도 이미지·아이콘 폰트 의존성은 추가하지 않았습니다.

색상은 Light/Dark 테마 리소스에 모으고 화면·입력창·자동완성·팝업 배경과 글자·테두리는 동적 리소스로 연결합니다. 테마는 애플리케이션 전체에서 전환하므로 이미 열려 있거나 이름이 숨겨진 가격 팝업에도 즉시 적용됩니다. `theme.txt`에 `light` 또는 `dark`로 원자적으로 저장하고 파일이 없으면 라이트로 시작합니다.

상승·하락은 테마별 빨강·파랑을 사용합니다. 시장이 완전히 마감되면 종목명·현재가·등락률을 모두 테마별 회색으로 표시하고, 다시 열리면 마지막 유효 가격의 등락 색상으로 복귀합니다. 가격 팝업의 개장 여부는 정규장과 시간외 세션을 함께 판단합니다. 자세한 시세 범위는 [공개 시세 문서](PublicData.md)를 참고하세요.

## 새 가격창의 겹침 방지

새 가격창은 검색창 아래의 기존 위치를 먼저 사용합니다. 그 위치에 보이는 가격창이 있으면 4 DIP 간격으로 아래쪽 빈자리를 찾고, 화면 하단에 공간이 부족하면 위쪽으로 찾습니다. 가격창뿐 아니라 검색창 영역도 피합니다. 세로 방향이 모두 차면 같은 모니터의 옆 빈 열을 사용합니다. 화면의 물리적인 모든 공간이 찬 경우에는 기존의 화면 내 기본 위치를 유지합니다.

기존 창은 이동시키지 않습니다. 고정된 창과 첫 시세를 기다리는 창도 점유 영역으로 계산합니다. 새 창 자신, 닫힌 창, 최소화된 창은 제외하며 같은 종목을 다시 열 때는 교체된 이전 창을 제외합니다. 최초 응답이 늦더라도 사용자가 그 사이 새 창을 이동하거나 고정했다면 검색창 옆으로 되돌리지 않습니다.

화면 작업 영역과 창마다 다른 배율을 실제 화면 픽셀로 변환해 비교합니다. 가격 텍스트가 처음 채워지며 늘어나는 폭도 배치 계산에 포함합니다.
