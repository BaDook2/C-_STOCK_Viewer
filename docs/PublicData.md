# 키 없는 국내·미국 공개 시세 · 2026-11-11

국내 주식·ETF 가격은 토스증권 비로그인 웹 통합 시세를 사용합니다. 미국 프리·정규·애프터마켓은 네이버 공개 시세, 미국 데이마켓은 토스증권 공개 시세로 보완합니다. 증권사 로그인·API 키가 필요하지 않습니다. 이 경로들은 공식 Open API 계약을 사용하지 않으며 웹 서비스 변경·제한의 영향을 받을 수 있습니다. 키움 구현은 레거시로 남기고 앱에서 인증·주문·계좌 조회를 호출하지 않습니다.

## 종목 검색

종목 목록과 한글·초성·티커 자동완성은 기존 네이버 경로를 유지합니다. KOSPI/KOSDAQ 각각 상위 100개와 캐시를 시작 목록으로 사용하며 입력 후 250ms 뒤 원격 자동완성을 조회합니다. 국내 코드는 6자리 영숫자, 미국 코드는 실제 reutersCode를 US: 네임스페이스로 보존합니다. 국내 시세의 토스 제품 ID는 네이버 코드에 접두사를 붙여 추측하지 않고 토스 코드 조회 응답에서 검증합니다.

- [검색 응답](https://ac.stock.naver.com/ac?q=AAPL&target=stock&st=111)
- [국내 목록](https://m.stock.naver.com/api/stocks/marketValue/KOSPI?page=1&pageSize=100)

## 국내 토스 통합 시세

- 새 deviceId·탭 ID와 메모리 쿠키로 익명 방문자를 만들고 `GET https://wts-api.tossinvest.com/api/v3/init?tabId=...`를 호출합니다. 기존 브라우저의 로그인 쿠키나 계정·키 파일을 읽지 않고 쿠키를 디스크에 저장하지 않습니다.
- `GET https://wts-info-api.tossinvest.com/api/v2/stock-infos/code-or-symbol/{symbol}`에서 제품 ID·원래 코드·KRW 통화·국내 시장을 검증합니다. ETF·ETN·영숫자 코드도 같은 방식으로 확인합니다.
- `GET /api/v5/stock-prices?productCodes=...&localizedCurrency=KRW`에서 `marketCurrency=KRW`, 유효한 `close`, `base`, `dt`, `exchange`를 확인합니다. 기본 조회가 제공하는 통합 현재가를 그대로 사용하며 앱에서 KRX와 NXT 중 하나를 다시 선택하지 않습니다. KRX 전용 응답은 KRX로 표시합니다.
- 등락률은 `(close / base - 1) * 100`으로 계산합니다. 기준가는 제공처가 보낸 값을 사용하며 수신 시각으로 기준시각을 만들어 채우지 않습니다. 잘못된 통화·종목·가격·기준가·미래 시각의 행은 버리고 다른 정상 종목은 유지합니다.
- 토스의 `/api/v2/system/trading-hours/integrated` 응답 중 `ats`에 포함된 날짜별 KRX/NXT 거래시간을 사용합니다. NXT 지원 정보와 `/api/v1/mds/info/krx-extended-hour-support-yn/{productCode}`의 당일 KRX 시간외 지원 여부를 확인합니다. NXT 미지원 ETF를 NXT 애프터마켓 개장만으로 열린 종목으로 처리하지 않습니다.
- KRX·NXT 정규장, 프리·애프터마켓과 종가 거래 구간을 판정합니다. 지원하는 거래 구간이 열려 있으면 OPEN, 전체 마감 또는 명시된 휴일은 CLOSE입니다. 달력·관련 시간외 지원이 불확실하면 UNKNOWN으로 처리하며 네트워크 실패를 마감으로 표시하지 않습니다.
- 가격·제품 ID·거래일 달력은 캐시하며 거래시간은 30초, 종목 지원 정보는 최대 1분 후 재확인합니다. 시간외 지원은 당일 날짜가 일치해야 사용하고 날짜가 바뀌면 다시 확인합니다.
- 국내 오류·누락 때 네이버 국내 시세로 자동 전환하지 않습니다. 마지막 유효 가격과 완전히 불투명한 배경을 유지하고 연결 지연을 알립니다. 다음 정상 응답에서 자동 복구합니다.

2026-11-11 실제 C# 서비스에서 삼성전자·SK하이닉스의 KRX+NXT 통합 현재가, KODEX 200 ETF의 KRX 현재가·원화·기준시각을 확인했습니다. 국내·미국 동시 연속 수신에서 국내 평균 0.990초, 미국 평균 0.996초를 확인했습니다. 개별 시점의 측정이며 지연 없는 체결 스트림을 보장하지 않습니다. 프리·애프터마켓·휴일·전일 마감→다음 개장은 제공처 형식의 가상 HTTP 응답으로 회귀 검증합니다.

## 폴링·수신 오류

국내·미국은 독립 작업·게이트·캐시·요청 제한 상태를 사용하고 최대 20종목씩 묶어 1초 목표로 조회합니다. 1초보다 오래 걸리는 요청 뒤에는 최소 50ms를 둡니다. 종목별 오류는 1·2·4·8·10초 간격으로 재시도하며 정상 종목은 계속 갱신합니다. HTTP 429 또는 실패 응답에 Retry-After가 있으면 그 기간 추가 요청을 중단합니다. 마지막 팝업 종료 시 조회를 중단하고 앱 종료 시 초기 조회·정기 조회를 취소합니다.

HTTP 수신 시각과 제공처 기준시각을 구분합니다. 더 오래된 기준시각의 응답으로 새 가격을 덮어쓰지 않으며, 가격을 유지하는 경우에도 최신 수신 상태를 보존합니다. 마감 중에도 조회하므로 다음 개장에 기존 팝업의 색상·가격이 복구됩니다.

## 미국 네이버 시세

미국은 `GET https://polling.finance.naver.com/api/realtime/worldstock/stock/{reutersCode}`를 사용합니다. 제공처의 지연 안내·통화·장 상태·기준시각을 보존합니다. 유효한 프리·애프터마켓 가격이 정규장보다 최신이면 반영하며 USD 가격을 소수점 최소 두 자리로 표시합니다. 장후 등락률의 당일 종가 기준을 전일 종가 기준으로 환산합니다. 공개 응답의 pollingInterval은 참고 메타데이터이며 1초 조회 목표를 바꾸지 않습니다.

## 미국 데이마켓 보완

네이버의 미국 `overMarketPriceInfo`는 애프터마켓 마감 후 움직이지 않아, 이것만으로 미국 전체 마감 여부를 판단할 수 없습니다. 미국 데이마켓은 토스증권의 공개 웹 시세를 보조 피드로 사용합니다.

- 새로운 익명 방문자 식별자·쿠키와 탭 식별자를 메모리에 만들고 공식 공개 방문자 초기화 `GET https://wts-api.tossinvest.com/api/v3/init?tabId=...`를 사용합니다. 기존 브라우저 쿠키·계정·로그인 티켓은 읽지 않습니다. 이 쿠키를 설정 파일에 저장하지 않습니다.
- `POST https://wts-info-api.tossinvest.com/api/v3/search-all/wts-auto-complete`에서 네이버의 실제 표시 티커와 일치하는 종목을 찾습니다. `GET /api/v2/stock-infos/{productCode}`에서 티커·USD 통화·`daytimePriceSupported`를 재확인합니다. 거래소 접미사나 상장일로 제품 ID를 추측하지 않습니다.
- `GET https://wts-api.tossinvest.com/api/v2/system/trading-hours/integrated`의 거래일별 `dayMarketStart`/`dayMarketEnd`를 사용합니다. 시간은 제공처 정의대로 한국 시간으로 해석하고 달력은 1분 캐시합니다. 휴일·서머타임·운영시간 변경도 이 달력에 따릅니다.
- `GET https://wts-info-api.tossinvest.com/api/v5/stock-prices?productCodes=...&localizedCurrency=KRW`에서 `marketCurrency=USD`, `session=DAY_PRE_MAIN`, `close`, `base`, `dt`를 검증합니다. 가격은 달러 값을 사용하고 등락률은 `(close / base - 1) × 100`으로 계산합니다. 원화 환산값을 달러로 표시하지 않습니다.
- 네이버와 데이마켓 중 최신 체결 시각의 유효 가격을 선택합니다. 체결 시각은 제공처의 실제 `dt`를 사용하며 수신 시각으로 만들어 채우지 않습니다. 데이마켓 종료 후에도 마지막 데이마켓 가격을 보존하고 다음 피드가 더 최신인 체결을 제공할 때 교체합니다.
- 데이마켓이 열려 있는 종목은 정규·애프터마켓이 닫혀도 마감 회색으로 표시하지 않습니다. 데이마켓을 확인할 수 없으면 `UNKNOWN` 상태와 연결 지연을 알리고 마지막 가격을 유지합니다. 정상적인 휴장·마감과 피드 실패를 구분합니다.
- 데이마켓의 HTTP Retry-After는 독립적으로 준수합니다. 네이버 요청 제한 중에도 데이마켓 시세가 유효하면 계속 표시합니다.

2026-11-10 실제 조회에서 애플·SPY·버크셔의 데이마켓 가격·체결 시각과 약 1초 간격 갱신을 C# 실행으로 확인했습니다. 새 피드는 [토스증권 애플 공개 화면](https://www.tossinvest.com/stocks/US19801212001)에서 사용하는 공개 경로를 확인한 것입니다. 매매·계좌·인증 API는 사용하지 않습니다.
