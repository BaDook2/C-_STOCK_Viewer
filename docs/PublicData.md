# 키 없는 국내·미국 공개 시세 · 2026-11-10

증권사 계정·API 키 없이 네이버 공개 시세·검색 JSON과 토스증권의 비로그인 미국 데이마켓 JSON을 조회합니다. 외부 네트워크는 필요하며, 공개 웹 데이터는 정식 증권사 체결 스트림과 다릅니다. 기존 키움 구현은 레거시 코드로만 보존하고 앱에서는 인증·키 저장·WebSocket 연결을 호출하지 않습니다. 기존에 저장한 키 파일도 자동으로 읽거나 삭제하지 않습니다.

- [코스피 기본 목록](https://m.stock.naver.com/api/stocks/marketValue/KOSPI?page=1&pageSize=100)
- [네이버 원본 종목 화면](https://m.stock.naver.com/domestic/stock/005930/total)

네이버를 사용하는 이유는 기존 국내 시세와 같은 경로로 국내·미국 검색, 한글 종목명, 주식·ETF를 함께 지원하며 API 키 입력이 필요 없기 때문입니다. [Alpaca 공식 문서](https://docs.alpaca.markets/us/docs/market-data-faq)에 따르면 Alpaca는 인증 키가 필요하고 무료 실시간 피드는 단일 IEX 거래소 데이터이며 통합 SIP 실시간 데이터는 별도 구독이 필요합니다. 이 앱의 키 없는 간단한 사용 방식에는 네이버 경로가 적합합니다. 정식 개발자 계약이나 가용성 보장을 제공하는 API로 간주하지 않습니다.

시작 시 KOSPI/KOSDAQ 각각 상위 100개와 캐시를 기본 목록으로 사용합니다. 입력마다 250ms 대기 후 공개 자동완성을 조회하여 초기 목록 밖의 국내·미국 주식·ETF·영숫자 종목코드도 검색합니다. 이전 입력 요청은 취소하고 현재 입력의 결과만 반영합니다. 미국 종목은 `nationCode=USA`인 검색 응답의 `reutersCode`를 그대로 사용합니다. `AAPL.O`, `SPY`, `BRKb`처럼 식별자가 달라 거래소별 접미사를 임의로 만들지 않습니다. 화면에는 `AAPL`, `SPY`, `BRK B` 같은 티커를 표시합니다.

가격은 국내·미국의 독립 작업에서 최대 20개씩 묶어 조회합니다. 시장별 네트워크 게이트·깨우기 신호·캐시를 분리해 한 시장의 응답 지연이 다른 시장을 막지 않습니다. 같은 종목의 초기 조회와 정기 조회는 캐시와 다음 조회 시각을 공유합니다. 마지막 팝업이 닫히면 양쪽 조회를 중단합니다.

v1.1.2부터 조회 목표는 1초입니다. 응답의 `pollingInterval`은 ProviderPollingInterval에 참고 정보로 보관하고 대기 기준으로 사용하지 않습니다. 네트워크 완료 뒤 다시 1초를 더하지 않고 요청 시작 시점에 다음 주기를 맞춥니다. 응답이 1초보다 오래 걸리면 완료 후 최소 50ms를 두며 같은 시장의 요청은 겹치지 않습니다. HTTP 제한이 있으면 아래의 Retry-After 처리가 우선합니다. 안내 간격 형식이 잘못돼도 유효한 가격을 버리지 않습니다.

2026-11-05 직접 1초 간격으로 세 번 확인한 삼성전자 응답은 안내 값이 7초였지만 실제 가격과 기준 시각이 각 응답에서 바뀌었습니다. 같은 확인에서 미국 응답 안내 값은 70초이고 시장은 마감 상태였습니다. 빠른 조회가 제공처의 체결 데이터 자체를 더 빠르게 만드는 것은 아니며, 1초 시세 반영의 가용성이나 제공처의 향후 제한 정책을 보장하지 않습니다. Cache-Control: no-cache와 Pragma: no-cache로 캐시 재검증을 요청합니다.

`closePrice`는 현재가, `fluctuationsRatio`는 전일 대비 등락률입니다. `compareToPreviousPrice.code`가 하락을 뜻하면 비율의 음수 부호를 보정합니다. `localTradedAt`과 `marketStatus`를 보존해 툴팁에 기준 날짜·시각과 장 마감을 표시합니다. 이전 기준 시각의 응답으로 새 가격을 덮어쓰지 않습니다.

공개 시세의 새 응답에 localTradedAt이 빠져도 최신 수신 시각의 가격은 반영합니다. 시각 없는 응답 뒤에도 마지막으로 확인한 체결 시각을 별도로 보존하여 그보다 오래된 시세가 가격을 덮어쓰지 않게 합니다. 툴팁 수신 시각은 실제 새 HTTP 응답에서 갱신하므로 가격이 같거나 오래된 시세를 보존하는 경우에도 조회 상태를 구분할 수 있습니다. 레거시 키움 틱을 오래된 조회 스냅샷으로 덮지 않는 처리는 별도로 유지합니다.

미국은 USD 가격을 소수점 최소 두 자리, 최대 네 자리로 표시합니다. `overMarketPriceInfo`에 정규장보다 최신인 `PRE_MARKET`/`AFTER_MARKET` 가격이 있으면 해당 가격을 사용합니다. 프리마켓은 최근 정규장 종가를 전일 기준으로 사용하고, 애프터마켓은 정규장 가격과 전일 대비 변동액에서 전일 종가를 구한 뒤 `(최신 가격 / 전일 종가 - 1) × 100`으로 계산합니다. 장후 응답의 자체 등락률은 당일 정규장 종가 기준이므로 그대로 사용하지 않습니다. 시간·가격·전일 기준이 불완전하면 유효한 정규장 가격을 유지합니다. 미국 데이마켓은 아래의 별도 공개 피드로 보완합니다.

HTTP 429와 실패 응답의 Retry-After는 지정 시간 동안 추가 네트워크 조회를 막습니다. 동시에 여러 제한 응답이 오면 더 긴 대기 시간을 유지합니다. 일반 오류·종목 누락은 해당 종목만 1·2·4·8·10초 간격으로 재시도하고 성공하면 즉시 1초 목표로 복귀합니다. 정상 종목의 조회와 연결 상태는 유지합니다. HTTP 요청 시간 제한은 5초이며, 서비스 종료는 초기 조회와 정기 조회를 모두 취소합니다. 시세 형식 변경·응답 누락을 0원이나 예시 가격으로 대체하지 않습니다. 공개 경로는 제공처에서 변경·제한할 수 있습니다.

## 시간외 시세와 장 마감 표시

국내 기본 응답의 가격·상태는 거래소가 제공하는 현재 세션을 따릅니다. KRX 애프터마켓의 `marketSessionType=afterMarket`도 정규장 시각으로 차단하지 않고 계속 반영합니다. [네이버의 KRX 거래시간 연장 안내](https://help.pay.naver.com/faq/content.help?faqId=18245)를 참고했습니다.

국내 기본 응답의 `overMarketPriceInfo`(호환 필드 `nxtOverMarketPriceInfo`)는 NXT 시세입니다. `PRE_MARKET`, `REGULAR_MARKET`, `AFTER_MARKET`의 유효한 가격·일별 등락률·기준 시각을 읽고 KRX와 비교해 최신 가격을 선택합니다. 국내 NXT 등락률은 전일 기준 값을 그대로 사용하며 방향 코드를 보정합니다. 제공되지 않는 종목 또는 잘못된 시간외 가격은 유효한 KRX 가격을 유지합니다.

미국 프리·애프터마켓은 기존 전일 기준 등락률 계산을 유지합니다. 정규장과 같은 시각의 첫 시간외 체결도 열린 세션이면 반영하며, 정규장 시각이 누락돼도 시간외 가격·시각과 전일 기준이 유효하면 사용합니다.

가격의 최신성과 세션의 개장 여부는 분리합니다. 정규장 또는 지원하는 시간외 세션 중 하나라도 `OPEN`이면 열린 시장입니다. 열린 세션이 없고 제공처가 `CLOSE`를 보고할 때만 마감 색상을 적용합니다. 정규장 종료만으로 NXT나 미국 프리·애프터마켓을 회색 처리하지 않습니다. 시간외 가격이 아직 없거나 잘못돼도 유효한 `OPEN` 상태는 반영합니다. 최신 수신 상태는 보존하면서 오래된 체결 가격으로의 역행은 계속 막습니다.

이 판단에는 컴퓨터의 단순한 요일·고정 시각 대신 제공처의 세션 상태를 사용합니다. 휴장·조기 폐장·미국 서머타임도 제공처가 보고하는 상태를 따릅니다. 마감 중에도 폴링을 멈추지 않으므로 다음 세션이 열리면 같은 팝업에서 자동으로 색상과 가격이 갱신됩니다. 네트워크 오류만으로 마감으로 판단하지 않습니다.

지원 범위는 네이버의 국내 KRX/NXT·미국 프리/정규/애프터마켓과 토스증권의 미국 데이마켓입니다. 데이마켓 거래 대상이 아닌 종목이나 제공처가 지원하지 않는 시장의 가격을 만들어 표시하지 않습니다.

2026-11-10 확인: [국내 KRX+NXT 응답](https://polling.finance.naver.com/api/realtime/domestic/stock/005930,000660,069500), [NXT 전용 응답](https://polling.finance.naver.com/api/realtime/domestic/NXT/stock/005930), [미국 정규+시간외 응답](https://polling.finance.naver.com/api/realtime/worldstock/stock/AAPL.O,SPY). 실제 응답을 비교하고 세션 종료→시간외 개장→완전 마감→다음 프리마켓을 가상 HTTP 응답으로 연속 검증합니다. 실제 시장 전체 시간대의 경과를 기다려 검증한 것은 아닙니다.

## 미국 데이마켓 보완

네이버의 미국 `overMarketPriceInfo`는 애프터마켓 마감 후 움직이지 않아, 이것만으로 미국 전체 마감 여부를 판단할 수 없습니다. 미국 데이마켓은 토스증권의 공개 웹 시세를 보조 피드로 사용합니다.

- 새로운 익명 방문자 식별자·쿠키와 탭 식별자를 메모리에 만들고 공식 공개 방문자 초기화 `GET https://wts-api.tossinvest.com/api/v3/init?tabId=...`를 사용합니다. 기존 브라우저 쿠키·계정·로그인 티켓은 읽지 않습니다. 이 쿠키를 설정 파일에 저장하지 않습니다.
- `POST https://wts-info-api.tossinvest.com/api/v3/search-all/wts-auto-complete`에서 네이버의 실제 표시 티커와 일치하는 종목을 찾습니다. `GET /api/v2/stock-infos/{productCode}`에서 티커·USD 통화·`daytimePriceSupported`를 재확인합니다. 거래소 접미사나 상장일로 제품 ID를 추측하지 않습니다.
- `GET https://wts-api.tossinvest.com/api/v2/system/trading-hours/integrated`의 거래일별 `dayMarketStart`/`dayMarketEnd`를 사용합니다. 시간은 제공처 정의대로 한국 시간으로 해석하고 달력은 1분 캐시합니다. 휴일·서머타임·운영시간 변경도 이 달력에 따릅니다.
- `GET https://wts-info-api.tossinvest.com/api/v5/stock-prices?productCodes=...&localizedCurrency=KRW`에서 `marketCurrency=USD`, `session=DAY_PRE_MAIN`, `close`, `base`, `dt`를 검증합니다. 가격은 달러 값을 사용하고 등락률은 `(close / base - 1) × 100`으로 계산합니다. 원화 환산값을 달러로 표시하지 않습니다.
- 네이버와 데이마켓 중 최신 체결 시각의 유효 가격을 선택합니다. 체결 시각은 제공처의 실제 `dt`를 사용하며 수신 시각으로 만들어 채우지 않습니다. 데이마켓 종료 후에도 마지막 데이마켓 가격을 보존하고 다음 피드가 더 최신인 체결을 제공할 때 교체합니다.
- 데이마켓이 열려 있는 종목은 정규·애프터마켓이 닫혀도 마감 회색으로 표시하지 않습니다. 데이마켓을 확인할 수 없으면 `UNKNOWN` 상태와 연결 지연을 알리고 마지막 가격을 유지합니다. 정상적인 휴장·마감과 피드 실패를 구분합니다.
- 데이마켓의 HTTP Retry-After는 독립적으로 준수합니다. 네이버 요청 제한 중에도 데이마켓 시세가 유효하면 계속 표시합니다.

2026-11-10 실제 조회에서 애플·SPY·버크셔의 데이마켓 가격·체결 시각과 약 1초 간격 갱신을 C# 실행으로 확인했습니다. 새 피드는 [토스증권 애플 공개 화면](https://www.tossinvest.com/stocks/US19801212001)에서 사용하는 공개 경로를 확인한 것입니다. 매매·계좌·인증 API는 사용하지 않습니다.
